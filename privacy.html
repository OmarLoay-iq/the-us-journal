Privacy, plainly explained

What this version does

This is a static reading website. Its code does not ask you to create an account, collect form submissions, run analytics, load an advertising network, or set cookies. Search and topic filters work in your browser. Search terms are not sent to a server by our code.

The optional “Copy page link” button writes the current page address to your clipboard only when you click it. If copying is unavailable, your browser address bar remains available.

Hosting and external services

The site is prepared for GitHub Pages. The hosting provider may process ordinary request information, including IP address, browser information, and access logs, under its own privacy policy. The site operator does not claim that hosting is free of data processing.

If you follow a link to another website, that website’s privacy practices apply. No third-party fonts, embedded media, or advertising scripts are included in this version.

Changes to the site

Any future addition of analytics, advertising, email signup, or other data collection should be reflected here before it goes live. Depending on the service and audience, additional disclosures or consent controls may be needed.

This version is intended for adult readers and is not designed to collect information from children. Last updated: November 11, 2026.
